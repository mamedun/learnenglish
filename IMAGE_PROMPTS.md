# Google Flow illustration prompt pack — SpeakUp

These prompts document the Google Flow artwork. The images you attached have now been copied into the project and wired into the relevant lessons. Source files live under `public/images/...`; Vite publishes them under `/learnenglish/images/...` in production. The original market image remains in the project, and the supplied Flow market illustration is the version currently used in the picture-speaking unit.

## Style guide (apply to every prompt)

- Editorial illustration for an adult English-learning app: warm, calm, optimistic, polished, contemporary, human and inclusive.
- Soft sage/forest green, cream, muted terracotta and gentle lilac; natural light; clean shapes; uncluttered composition.
- Wide landscape 3:2 composition, high resolution (at least 1500 × 1000 px), subject readable when cropped to a card.
- No text, letters, captions, logos, flags, watermarks, signage that can be read, or UI overlays. Avoid stereotypes and exaggerated expressions.
- Keep important faces/objects in the centre 70% so mobile crops stay usable. Create a single coherent illustration, not a collage.

## How to add a generated file

The attached files have already been placed and integrated:

- Listening cards use the seven supplied illustrations through `src/listening.ts`.
- The A2 market picture task uses `/learnenglish/images/speaking/market-conversation-scene-flow.jpg`.
- IELTS-style Part 2 speaking units use `/learnenglish/images/speaking/speaking-cue-card-practice.jpg` as a supplementary visual.

For future images, review/crop the Flow export, save a JPEG under the matching `public/images/...` source directory, add the production URL to the lesson/unit data, run `npm run build`, and verify the URL under `/learnenglish/images/...`. Never describe an illustration as an official IELTS test part.

Do not add fabricated video imagery or lesson activities. Illustrations support context only; Listening answers remain tied to the fixed audio script and deterministic answer key.
